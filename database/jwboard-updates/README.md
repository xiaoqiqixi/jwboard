# JWBoard 版本化数据库更新

每个需要数据库变更的 JWBoard 发布版本，在本目录新建一个 SQL 文件，文件名必须为：

```text
主版本.次版本.修订版本.sql
```

例如 `1.0.2.sql`。`jwboard:update` 会读取数据库的 `v2_jwboard_update_log`：

- 1.0.0 升级到 1.0.2：依次执行 `1.0.1.sql`、`1.0.2.sql`；
- 1.0.1 升级到 1.0.2：只执行 `1.0.2.sql`；
- 已写入记录的 SQL 文件不会重复执行。

SQL 必须是面向升级路径的增量修改，不能包含 `DROP TABLE` 或依赖手工执行顺序的操作。更新成功后再写入迁移记录；失败时脚本会停止，保留错误以便处理。
